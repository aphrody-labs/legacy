# Repository layout

Target: the root of `oven-sh/bun` (read live on 2026-11-15 with `gh api repos/oven-sh/bun/contents/`): a flat root of manifests and a few directories (`bench`, `completions`, `docs`, `packages`, `patches`, `scripts`, `src`, `test`, `tools`). A root entry stays only when a Bun precedent or a reader that requires the path justifies it. A reader is a tool or code that opens the path; it is proven with `git grep -n -F <name>` before every decision. Moves use `git mv` and every reference is rewritten in the same commit. No archive: git is the history.

Decisions: keep, move, merge, purge. Status: done (commit in git log), pending, or blocked (reason).
