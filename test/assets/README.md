> Asset validators for assets/library: FFmpeg (tv-ffmpeg) decode of audio, resvg render of SVG, craft-formats probe, glTF structural validation and a headless Bevy load, TTF/OTF parse. Prints one JSON line per asset.

| Type | Path |
| :-- | :-- |
| Rust crate | `test/assets` |

**Commands**

```sh
cargo test -p asset-test
cargo run -p asset-test --bin asset-test
```

Rust builds run on the build host or in CI, not on a workstation.

Part of Aphrody: [aphrody-labs/ay](../../README.md), [Catalog](../../docs/reference/catalog/crate.md).
