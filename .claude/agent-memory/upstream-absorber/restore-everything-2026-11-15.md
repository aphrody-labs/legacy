Inventory lives in `docs/project/restore-inventory.{md,json}`, generated by `scripts/restore-inventory.ts` from `restore-github.ts`, `restore-registries.ts` + `restore-compare-registries.ts`, `restore-vps-scan.sh`, `restore-history.ts`. Restore tools: `restore-import.ts` (repo or dir), `restore-pkg.ts` (npm tarball or crate), `restore-history-extract.ts` (dir as of `<commit>^`, `--gone-only`, `--only <regex>`). All run gitleaks first, never overwrite (`--overwrite` only for dirs of the same run).

**Why:** owner asked to recover everything ever published or deleted (370 crates and 696 npm packages of the maintainer, 1127 GitHub repos, VPS trees, history deletions). Rules that changed mid-run: Python and Go stay Python and Go in their domain (no py2bun); the purged layer (Sovereign, brand, demos, the Go `src-deploy` engine, ai-os polyglot kernel) is not restored.

**How to apply:**
- `scripts/hygiene.ts` scans tracked files only: to gate untracked files copy them into a temp `git init` and pass `--root`; `--rule personal-data` is the one that bites (home path, mailboxes, host names, public IPs).
- gitleaks 8.30.1 is in `~/.local/bin` (`gitleaks dir <path> --redact=100 -f json -r out`).
- `plugins/` is gitignored (plugins/labs could not be committed); `scripts/commit.ts` can fail at the shared-index resync (`index.lock`) after the commit exists: check `git log` before re-running, then `git push aphrody main` (another session may already have pushed it).
- The temp dir was cleaned mid-run by another process (compare.json vanished): keep intermediate JSON where regeneration is cheap or rerun the stage.
- Treeless clone (`--filter=blob:none --depth 1`) plus `ls-tree -r` compares remote content by blob oid without downloading blobs; tarballs are hashed in memory.
- `ssh prd` repos can fail `git fetch` (bad pack header); `gh api` `--jq` breaks, pipe to jaq. fr2 `/tmp` has a small tmpfs quota.
- Old monorepo history before 2026-11-11 is not in `C:\aphrody` (rewritten); archived GitHub units ("Merged into aphrody-dev/src at ...") and the registries are the only copies of that era.

## 2026-11-16 additions
- Checkout moved to `C:\aphrody` (scripts derive the root from `import.meta.dir`). Other sessions restore the same lists in parallel (src/tauri, src/backend..., npm packages): check `git status` untracked dirs before importing anything.
- `ssh fr1 'pkill -f "cargo build --release"'` matches its own shell and every cargo of the shared user: start jobs from a script file and kill by pid only.
- Real UI proof recipe without a display: vite dev on fr1 plus headless google-chrome driven by a ~40 line CDP script (Bun WebSocket), ollama on fr2 reached through a PC hub (`ssh -L` from fr2, `ssh -R` to fr1); fr2 has about 2 GB disk and no webkit2gtk, fr1 has webkit2gtk 2.52 and OpenSSL 4 (openssl-sys needs >= 0.9.118 and openssl >= 0.10.78).
- `restore-import --dir` on Windows used to copy `.git` and browser profiles (backslash paths): fixed; check for nested `.git` after any dir import.
- Tauri builds need stub sidecars (`bin/<name>-<triple>`) listed in tauri.conf.json and tauri.<os>.conf.json.
