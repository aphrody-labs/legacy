# Shared LLVM and WebAssembly toolchain

- Design and per-language table (clang, rustc, lld, LTO flags): `docs/native/llvm/UNIFIED-TOOLCHAIN.md`; native specs: `docs/native/README.md`.
- Pins: `third_party/toolchain-<milestone>.toml` (clang and rustc built on one LLVM revision, Chromium's `update.py` / `update_rust.py` revisions) and `third_party/chrome-channels.toml`. Read the version from these files or from `clang --version` / `rustc -vV`, never from prose.
- C and Wasm core: `make -C src` (`src/Makefile`: `clang` for native, the wasi-sdk clang from `~/.local/share/ay/tools/` for Wasm via `WASI_CC`, `wasm-opt` and `wasm-validate` for post-processing). Validate with `wasm-validate --enable-all <file>.wasm`.
- Install and check: `bun scripts/toolchain.ts install|status|env|bin` (generation = the channel of `rust-toolchain.toml`, nothing else names it). C core tooling on that LLVM: `make -C src sanitize` (ASan + UBSan driver `src/tests/sanitize.c`), `tidy` (`src/.clang-tidy`), `format`, `size`; CI: `.github/workflows/llvm.yml` (C core job, llvm-cov of C and Rust, release size report). Variant measurements of `ay`: `docs/native/BUILD-SCIENCE.md` (table generated by `scripts/bench/llvm-table.ts`).
- Switch the generation: `just toolchain` (list, status), `just toolchain-use <milestone>` (rewrites the `channel` line of `rust-toolchain.toml`, installs). A new generation is one `third_party/toolchain-<milestone>.toml` (revisions of Chromium's `update.py` / `update_rust.py`, package hashes); scripts, CI and docs name no number. The rust package has no `rust-lld`: Linux links through `cc` or clang + lld, Windows through `lld-link` (`.cargo/config.toml`); llvm-profdata, llvm-cov, llvm-objdump and clang-tidy come with the packages, llvm-bolt, llvm-size and clang-format do not (the C-core format check uses the runner's). Exceptions: Alpine musl images (no musl std in the Chromium package), the bun fork workspace.
- Installed on the PC: `C:\Program Files\LLVM\bin` (clang, lld-link, wasm-ld), `~/.local/bin` (`wasm-opt`, `wasm-validate`). Heavy builds (Chromium, LLVM) run on fr1, see skill `fleet`.
- C ABI consumers: `src/core/capi` (Rust side), `system/core-ts/src/ffi.ts` (Bun side); round trip: `bun test system/core-ts`. The cc build script is `src/core/build.rs` (test: `src/core/tests/registry.rs`).
- Find users of a symbol: `bun system/core-ts/src/cli.ts users <name>`; reindex first with `bun system/core-ts/src/cli.ts index <root> --all`.
- Upstream sources: `third_party/llvm-project` (docs at https://llvm.org/docs/).
