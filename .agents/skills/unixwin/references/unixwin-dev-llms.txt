# UNIXWIN

> AI-native bash family — real bash syntax, real Unix commands, native Windows/Linux/macOS.

Updates: fast-moving project — performance & compatibility improve daily; for the latest, see the Changelog (https://unixwin.dev/changelog/) and GitHub Releases (https://github.com/unixwin/niubash/releases).

## Quick Start

```
winget install --id Unixwin.Niubash --source winget
# or: irm https://unixwin.dev/install.ps1 | iex
```

## Products

- [niubash](https://unixwin.dev/#niubash): AI-native real bash: real syntax, real Unix commands, native on Windows/Linux/macOS.
- [WinuxCmd](https://unixwin.dev/#winuxcmd): Native-Windows Unix command set, single ~3 MB executable.
- [rubash](https://unixwin.dev/#rubash): Embeddable GNU Bash 5.3-compatible engine.
- [niu-git](https://unixwin.dev/#niu-git): Native Windows Git without MSYS; git starts in ~14 ms (Windows, same-machine measurement).
- [wpm](https://unixwin.dev/#wpm): WinuxCmd's built-in package manager with a 282-package official index.
- [oh-my-niu](https://unixwin.dev/#oh-my-niu): Oh-My-style framework: 40+ themes and plugins.
