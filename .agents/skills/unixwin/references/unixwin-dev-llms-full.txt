# UNIXWIN

> AI-native bash family — real bash syntax, real Unix commands, native Windows/Linux/macOS. No WSL, no MSYS.

This is the full-text companion of https://unixwin.dev/llms.txt (same data sources as the website; versions refresh from GitHub Releases at build time, last fetch 2026-11-03).

Updates: fast-moving project — performance & compatibility improve daily. For the latest, see the Changelog (https://unixwin.dev/changelog/) and GitHub Releases (https://github.com/unixwin/niubash/releases).

## Quick Start

```
winget install --id Unixwin.Niubash --source winget
# or: irm https://unixwin.dev/install.ps1 | iex
# verify:
niu --version
echo "SHELL=$SHELL"; uname -s
```

## Family facts (measured)

- GNU Bash upstream test suites: 83/83 passing, 82 套逐字节一致
- Unix commands bundled: 176+ (1,924 options)
- git startup (niu-git, Windows, same-machine): ~14 ms vs Git Bash 45–103 ms
- One-shot execution `niu -c true`: 19.8 ms (was 105.6 ms) — measured on Windows
- One-shot execution `niu -c 'true'` (Linux caliber, re-measured 2026-10-28): 4.14 ms (bare run p50 3.71 ms; GNU bash 5.3.20 2.67 / 2.60 ms — Linux same-machine, release builds)
- Installed family size: ≈16 MB, zero DLL dependencies
- Native platform builds: 5 (released: Windows x64/arm64, Linux x86_64/aarch64 glibc, macOS aarch64/x86_64, Android .zip; musl is built + smoke-tested but not released, OpenHarmony is a CI compile check only)
- Unit tests: rubash lib 1031 通过 / 0 失败（1.5.0 冻结树，2026-11-03）· niubash 1026 通过 / 0 失败（1.4.x 口径，2026-10-19）
- AI agents wired: 24 (15 work out of the box)

## FAQ

### How is niubash different from Git Bash / WSL?

niubash is a native Windows program written in Rust: no bundled MSYS emulation layer, no WSL VM. Git Bash heuristically rewrites path-looking arguments before spawn (the reason the MSYS_NO_PATHCONV incantation exists); niu passes argv through byte-for-byte. The installed family is ≈16 MB versus Git Bash's ~440 MB.

### Do I need WSL or MSYS to use niubash?

No. Bash semantics run directly on the Rust engine (rubash), Unix commands come from WinuxCmd (176+ commands), and Git from niu-git — all native binaries with zero DLL dependencies and zero telemetry in the shell.

### What does "83/83 GNU suites" mean?

All 83 upstream GNU Bash test suites pass on real hardware Windows, with 82 suites byte-identical to GNU Bash 5.3 output; the single residual line (nameref) is proven byte-by-byte to be GNU's own coproc reap race. Compatibility is measured, not claimed: a nightly patrol additionally sweeps 2,686 real-world ecosystem repos / 9,701 assets.

### How do I switch an agent's shell (Claude Code / Cursor etc.) to niubash, and how do I roll back?

Open the agent directory (/agents/): each of 24 mainstream agents has its own page with a copy-paste switch script, a real verify command (echo "SHELL=$SHELL"; uname -s) and rollback steps. AI users can also paste the install prompt from /ai/ and let the agent install and wire itself.

### Is it free? Which platforms are supported?

Everything is open source and free. niubash itself officially releases on four platforms: Windows x64 / arm64 (winget: Unixwin.Niubash), Linux x86_64 / aarch64, macOS x86_64 / aarch64, and Android (a .zip release artifact since v1.4.3). musl is build + smoke only and OpenHarmony is a CI compile check only — neither counts as an official release.

### How is the performance?

One-shot execution (niu -c true) is 19.8 ms after dedicated optimization (measured on Windows); re-measured under the Linux caliber (2026-10-28, release builds, 50-sample interleaved, Linux same-machine): niu -c 'true' 4.14 ms (bare run p50 3.71 ms), GNU bash 5.3.20 at 2.67 / 2.60 ms; niu-git starts in ~14 ms (measured on Windows, same machine; Git Bash on the same machine: 45–103 ms); command-substitution and subshell workloads run 13–62x faster than GNU bash. Every figure is labeled by platform and ships with its measurement method and reproducible artifacts — see Benchmarks (/benchmarks/).

### What is the relation between niu and niubash?

niu is the executable name of niubash (after winget install the command is niu). The family splits as: rubash (the embeddable Bash 5.3-compatible engine), WinuxCmd (Unix commands), niu-git (Git), wpm (package manager) and oh-my-niu (theme framework).

### What is the relation between rubash and niubash?

rubash is the language engine of niubash — it is what executes the bash syntax. It also stands alone: published on crates.io (1.5.0, cargo add rubash) as an embeddable GNU Bash 5.3-compatible engine.

### How do I embed rubash in my own program?

cargo add rubash (1.5.0) and use it as a library. The public Session contract (rubash::api — Session, completion and capability traits) shipped in rubash 1.5.0, so hosts consume the engine through the public surface; the four-tier workspace split and the move of 846 env-IPC sites to typed bridges remain follow-up work (design doc: rubash PR #814), and niubash is migrating its host wiring to the new API in the 1.5.1 cycle (niubash#863).

### How many builtins does rubash cover?

All 61 builtins of GNU Bash 5.3 plus the env extension (62); 12 high-frequency file commands execute inline with a pipeline inline arm — an echo | cat pipeline creates zero processes end to end.

### How does WinuxCmd differ from the Unix commands bundled with Git Bash?

WinuxCmd is a single native Win32 executable carrying 176 commands / 1,924 options (3.79 MB, zero DLLs). Git Bash provides similar commands through a ~440 MB MSYS emulation layer that rewrites path-looking arguments before spawn — WinuxCmd’s argv arrives byte-for-byte.

### How fast is WinuxCmd?

About 19 ms cold start (measured on Windows); with PGO builds sort is 18% faster and nl 17% (measured, per the README).

### What does "GNU differential" mean?

Every PR automatically runs a 178-case differential against GNU coreutils 9.7 (131 corpus cases over 67 commands + 47 regressions): 93% pass, with all 13 tracked platform differences named in the ledger — command behavior is measured, not claimed.

### How do wpm and WinuxCmd relate?

wpm is compiled straight into winuxcmd.exe (run as winuxcmd wpm) — zero runtime dependencies, no separate install step.

### How is niu-git different from Git for Windows?

The same git-for-windows C sources built natively with MSVC: no MSYS layer, no OpenSSL (TLS via schannel + the Windows cert store), no bundled shell/perl — launcher quoting follows the Win32 documentation with zero heuristics.

### Why is niu-git fast?

git starts in about 14 ms (Windows, same-machine measurement; Git Bash measures 45–103 ms) — no DLL loading or MSYS init chain, the process starts directly.

### How do I install niu-git?

It is preinstalled with niubash (x64 / arm64): git --version works out of the box, and POSIX-shaped /d/... arguments are accepted.

### How do I install wpm?

Nothing to install — it is compiled into winuxcmd.exe, so having WinuxCmd/niubash means having wpm: wpm prints help, wpm list browses the index, wpm install <pkg> installs.

### How many packages does wpm have? Is it safe?

The official index carries 282 packages, each with a sha256/size/urls triple; the cache key <pkg>-<version>-<sha8> double-checks, and the index tooling refuses to write entries for archives missing files.

### Is wpm fast to download from China?

Four mirror sources with gh.caomengxuan666.com accelerating China; sha256 remains the source of truth — mirrors accelerate, never substitute.

### Does wpm have a GUI?

A wpm-gui experiment was evaluated and archived due to CLI contract drift (wpm-gui#1) — the focus is a stable CLI, with --json output for scripts and agents.

### How do I enable oh-my-niu?

oh-my-niu is an independent repo and does not ship with niubash: clone it to ~/.niubash/oh-my-niu first (or unpack a release zip there). Then point NIUBASH at that directory in ~/.niubashrc and enable it with three lines: NIU_PLUGINS=(prompt-core git …) picks plugins, NIU_THEME=… picks the theme, source "$NIUBASH/oh-my-niu.niu" loads the framework. The entry is re-entrant (sourcing twice is a no-op, --reload forces a full reload).

### How do I change themes in oh-my-niu?

Edit NIU_THEME and reopen the terminal; the current session can hot-reload with source "$NIUBASH/oh-my-niu.niu" --reload. Each of the 27 themes is an ordinary plugin directory — there is no special "theme system".

### Can I run oh-my-bash themes and plugins?

Yes — niu plugin add oh-my-bash (the catalog points at the official upstream repo) runs upstream assets unmodified; oh-my-niu and external sources do not interfere and can coexist.

### How do I update oh-my-niu?

Updates are manual: git pull in the clone, or download a newer release zip from the oh-my-niu repo's GitHub Releases and unpack it over the old tree. It does not ship with niubash and does not advance via niu self-update. It is not a niu plugin source — niu plugin update oh-my-niu fails with "unknown source" (measured on niubash 1.4.4); the spec+lockfile mechanism governs external third-party sources.
