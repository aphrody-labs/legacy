# ui-system

Source of truth: `packages/design` (tokens, DESIGN.md, components), `docs/ui/STACK.md` (targets and sources).

## Targets

The design system is framework-neutral: one token set, one adapter per target. Pick the framework the surface already uses; do not add a second UI library to a surface. Adapters are generated by `packages/design/src/adapters.ts` into `packages/design/tokens/adapters/` (`bun run --cwd packages/design build` regenerates, `bun test --cwd packages/design` checks drift):

| Surface        | Token output to consume                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------------------------- |
| Web (CSS)      | `tokens/tokens.css`, `tokens/angular-material.css` + `tokens/angular-theme.scss`, `adapters/tailwind.css`, `adapters/shadcn.css`, `adapters/mui.json`, `adapters/fluent.json`, `adapters/webui-tokens.json` |
| Android        | `adapters/Theme.kt` (Compose), `adapters/ndk_theme.h` (NDK)                                                           |
| Flutter        | `adapters/aphrody_theme.dart`                                                                                         |
| Windows native | `adapters/winui.xaml`, `adapters/fluent.json`, `adapters/webui-tokens.json`                                           |
| Rust GPU / UI  | `tokens/tokens.rs`, `adapters/gpui-kit.json`, `egui_theme.rs`, `iced_theme.rs`, `bevy_theme.rs`, `cosmic_theme.ron`, `leptos_dioxus_tokens.rs`, `taffy_tokens.rs` |
| C / Zig        | `adapters/tokens.h`, `tokens/tokens.zig`                                                                              |
| TUI            | `tokens/ansi.json`, `tokens/ansi.sh`, `tokens/tokens.rs` (24-bit SGR)                                                 |

Defaults already in the repo: the web app `apps/aphrody/web` is an Angular app on Angular Material; `docs/ui/STACK.md` lists the sources and the dated version checks for each target. For a new surface, choose from the adapters above and record the choice in `docs/ui/STACK.md`.

## Rules

1. No color, radius, duration or font value copied: consume `tokens.css` (`var(--md-sys-color-primary)`), `tokens.json`, `tokens.rs` (`include!`), `tokens.zig` or `ansi.json`, or the adapter of the framework in use.
2. Brand color change: edit `packages/design/design.toml` (owned by the brand agent), then `bun run --cwd packages/design build`; `bun test --cwd packages/design` checks drift and AA contrast.
3. Angular web components: `import { APHRODY_MATERIAL } from "@aphrody/design/components"` in the `imports` of a standalone Angular component, then `<a matButton="filled">`, `<mat-card>`, `matInput`, etc. Theme: `@use "@aphrody/design/tokens/angular-theme"` (`--mat-sys-*` variables set on the `--md-sys-*` tokens). Icons: `@aphrody/design/symbols.css`, `<mat-icon fontSet="material-symbols-rounded">name</mat-icon>`. Build: `bunx --bun ng build` in `apps/aphrody/web`. Server-rendered pages without Angular use native HTML `.btn` on the same tokens.
4. Typography: Google Sans Flex (design.toml), M3 scale `--md-sys-typescale-*`. Shapes `--md-sys-shape-corner-*`. Motion `--md-sys-motion-*`.
5. bun only for JS/TS. Rust with windows-rs. No compilation on the PC: CI or fr1 under `nice -n 19`.
6. Commits: directly on main, limited to your paths, no AI attribution or emoji.
7. Verify every cited version live (`gh api`, npm registry, crates.io, context7, Microsoft Learn MCP) and note it with its date in `docs/ui/STACK.md`.

## Figma (Figma MCP)

- Load the Figma plugin skills before any call: `figma-use` (mandatory before `use_figma`), `figma-generate-library` (variables, components), `figma-generate-design` (screens), `figma-design-to-code` (before `get_design_context`), `figma-code-connect`.
- Reference file: `packages/design/tokens/figma.json` (Aphrody team, Professional plan, 4 modes per collection). Always `create_session` with this fileKey.
- Sync the variables: `bun run --cwd packages/design figma` produces `tokens/figma-sync.js`, to pass as is to `use_figma` (idempotent, `skillNames: "figma-use,figma-generate-library"`).
- Visual model: official Material 3 Design Kit (https://www.figma.com/community/file/1035203688168086460/material-3-design-kit), aligned `Schemes/<Role>` variable names.

## Stitch (relay MCP)

- `stitch` server built into the relay (`packages/ai-os/src/relay/mcp-hub.ts`, https://stitch.googleapis.com/mcp, gcloud token). Tools exposed as `mcp__relay__stitch__*` when the relay is connected.
- Give Stitch `packages/design/DESIGN.md` (google-labs-code/design.md format, alpha version) as the system; every Stitch mockup is then rebuilt in the framework of the target surface, never pasted.
- Lint: `ay design lint` (`aphrody-ui::design_md` linter in `src/ui/kit`, reads `packages/design/DESIGN.md` by default) or `bun run --cwd packages/design lint`; 0 errors required.

## Direction and critique (after anthropics/skills frontend-design, 41bbe19d1a1a)

The M3 tokens fix color, shape and motion; singularity comes from the subject, the composition, the type scale and a single standout moment.

1. Start from the real subject (product, audience, main task) and its real content; never lorem or invented figures.
2. Two-pass plan before the code: chosen M3 roles (scheme variant, containers), `--md-sys-typescale-*` scale used, ASCII mockup of the layout and alignment, two or three principles specific to the surface. Reread the plan: any part that would be the same for any neighboring product is redone.
3. One bold move per screen; the rest calm and disciplined. Remove one ornament before delivering.
4. Generic defaults to refuse unless explicitly requested: grid of identical cards with a gray shadow, spaced uppercase eyebrow above every heading, one heading word set in color or italic, 01/02/03 markers on content that is not a sequence, fade-slide on every section, "→" arrow added to links, decorative gradients, "A · B · C" strings.
5. Motion not triggered by the user: only one, orchestrated; motion that answers an action shows what changed.
6. Measure < 80 characters; one or two families at most (Google Sans Flex, plus Google Sans Code for code).
7. Text: user's point of view, active voice, a button says what it does and keeps its name across the flow ("Publish" then "Published"), errors that say what to do without apologizing. Skill `humanizer` before delivery. User-facing strings go through `@aphrody/i18n` with an English source.
8. Critique while building: screenshots (chrome-devtools MCP) at each step, responsive down to mobile, visible keyboard focus, reduced motion respected.

Detailed UX rules, product types, page structures and charts: skill `ui-ux-pro-max` (`bun .agents/skills/ui-ux-pro-max/scripts/search.ts`). 3D: skill `threejs-webgpu`.

## Assets

| Need              | Source                                                  | Use                                                                    |
| ----------------- | ------------------------------------------------------- | ---------------------------------------------------------------------- |
| Color scheme      | `@material/material-color-utilities`                    | already in `packages/design`                                           |
| Icons             | Material Symbols (`material-design-icons`)              | the icon library shipped                                               |
| Icons, reference  | `lucide`                                                | read-only, to draw a pictogram missing from Material Symbols           |
| Brand font        | Google Sans Flex (`design.toml`)                         | interface; details in `docs/ui/STACK.md`                               |
| Fallback fonts    | `roboto-flex`, `googlesans-code`, `geist-font`, `inter` | variable fallback, code, docs; subsetted woff2 on fr1                  |
| SVG: rendering    | `resvg` / `usvg`                                        | rasterization (favicons, preview PNGs, render tests)                   |
| SVG: optimization | `oxvg`                                                  | SVGO-compatible Rust optimizer, before any committed SVG               |
| 3D                | `three.js`, `wgpu`                                      | skill `threejs-webgpu`                                                 |

`resvg` and `oxvg` are compiled on fr1, never on the PC. None of these repositories is cloned under `third_party/` on this workstation; versions and sources: `docs/ui/STACK.md`.
