# Internationalization

- Source language is English everywhere: code, comments, docs, logs, CLI text. User-facing text lives in catalogs, never inline.
- `frameworks/i18n-ts` (`@auto/i18n`): one JSON catalog per locale in `frameworks/i18n-ts/locales/<tag>.json`, flat keys, values in Unicode MessageFormat 2 (engine: `messageformat` 4.x). `locales/config.json` names the source locale; `locales/registry.ts` lists the catalogs shipped (a test checks it matches the folder). Locales are whatever catalogs exist: no code path assumes a particular language.
- `createTranslator(locale, extra?)` returns `t(key, args)`, with fallback to the source locale then to the key, and `number`, `currency` and `date` through `Intl` with the negotiated locale. `extra` lets a package ship its own catalogs next to its code. Never format numbers, currencies or dates by hand.
- `matchLocale(tagOrAcceptLanguage)` negotiates against the shipped catalogs (quality order, language-only fallback, source locale otherwise).
- Adding a language: add `locales/<tag>.json` (same keys and placeholders as the source; `bun test frameworks/i18n-ts` enforces it) and list it in `registry.ts`.
- French legal and fiscal terms with no English equivalent (Factur-X, SIRET, TVA, FEC, URSSAF, ...) stay as data and are not translated.

## Migrated

- Landing page (`apps/web/src/site/accueil.tsx`, `public/index.html` head metadata): prerendered once per shipped locale; `/` negotiates `?lang=` then `Accept-Language`, with `Vary: Accept-Language`. In development the client render uses `navigator.languages`.

## Not migrated yet

Hardcoded French remains in the application screens (`apps/web/src/client`), the other static pages (`apps/web/public/*.html`), API error messages (`apps/api`), mail templates and notifications (`packages/mail`, `packages/services`), the Chrome extension and most docs. File and folder names (for example `docs/DEPLOIEMENT.md`, `apps/web/src/client/ecrans`) and many identifiers are French; they are public paths or stored data in places, so they are renamed only where local and safe.
