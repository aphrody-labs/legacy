# Aphrody Web Surface (`apps/web`)

<!-- catalog:begin unit -->
| Type | Path |
| :-- | :-- |
| App | `apps/web` |

Part of Aphrody: [aphrody-labs/aphrody](../../README.md), [Catalog](../../docs/reference/catalog/app.md).
<!-- catalog:end -->

Static HTML, Material 3 Expressive tokens, Pure-C WASI/WebGPU UI studio (`/m3/`), and WebAssembly/WebGPU Wayland compositor surface (`/wayland/`) for `aphrody.com` / `aphrody.app`.

- `public/` — home and catalog pages generated by [`build.ts`](build.ts) from `public/catalog.json` and `packages/i18n/catalogs/site` (`en`, `fr`), `/m3/` (generated by `ay-m3-site.wasm` built from [`../../src/ui/site_wasi.c`](../../src/ui/site_wasi.c) + `aysys.wasm`), `wayland.wasm` (built from [`../../src/wasm/compositor.c`](../../src/wasm/compositor.c) via [`../../src/Makefile`](../../src/Makefile)), `tokens.css`, `sitemap*.xml`, `robots.txt`, and `.well-known/*`.
- `assets/wayland/aphrody.desktop` — Freedesktop Wayland desktop entry.
