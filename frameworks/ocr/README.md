# aphrody-ocr

<!-- catalog:begin unit -->
<!-- prettier-ignore-start -->
> Image-to-text pipeline for aphrody: drives a local vision-language model over one image or a whole directory, parses its DocTags output into markdown, and reports which pages carry no text at all.

| Type | Path |
| :-- | :-- |
| Rust crate | `frameworks/ocr` |

**Commands**

```sh
cargo test -p aphrody-ocr
```

Rust builds run on the build host or in CI, not on a workstation.

Part of Aphrody: [aphrody-labs/ay](../../README.md), [Catalog](../../docs/reference/catalog/crate.md).
