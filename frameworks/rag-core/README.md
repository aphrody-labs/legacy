# aphrody-rag-core

<!-- catalog:begin unit -->
> Pure, wasm32-safe core of the aphrody RAG layer: source-aware chunkers (Rust/JS-TS/Markdown/structural/prose), reciprocal-rank-fusion + MMR + vector helpers, and a bit-for-bit port of shenron's retrieval eval harness.

| Type | Path |
| :-- | :-- |
| Rust crate | `frameworks/rag-core` |

**Commands**

```sh
cargo test -p aphrody-rag-core
```

Rust builds run on the build host or in CI, not on a workstation.
