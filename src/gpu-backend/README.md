# aphrody-gpu-backend

<!-- catalog:begin unit -->
> Shared wgpu instance, adapter, device and surface-configuration boundary for Aphrody and IECODE renderers, plus the process-wide GPU hub (wgpu + CUDA).

| Type | Path |
| :-- | :-- |
| Rust crate | `src/gpu-backend` |

**Commands**

```sh
cargo test -p aphrody-gpu-backend
```

Rust builds run on the build host or in CI, not on a workstation.

Part of Aphrody: [aphrody-labs/aphrody](../../README.md), [Catalog](../../docs/reference/catalog/crate.md).
