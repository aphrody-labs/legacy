> Rust core of the Aphrody design system: Material 3 color (HCT, schemes, contrast), tokens, component contracts, layout, theme presets, React/Next front ends and the brand renderer.

| Type | Path |
| :-- | :-- |
| Rust crate | `src/ui/kit` |

**Commands**

```sh
cargo test -p aphrody-ui
cargo run -p aphrody-ui --bin aphrody-brand
```

Rust builds run on the build host or in CI, not on a workstation.

Part of Aphrody: [aphrody-labs/aphrody](../../../README.md), [Catalog](../../../docs/reference/catalog/crate.md).
